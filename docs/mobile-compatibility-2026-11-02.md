# 词与远方：H5 适配检查

日期：2026-11-02。线上入口：https://west.cloud-ip.cc/

## 结论与范围

本轮线上移动端模拟的 14 组功能流程、144 组页面/尺寸/主题组合通过；未发现横向页面溢出或未处理的浏览器 JavaScript 异常。检查发现并上线修复了四处适配问题。该结论不等于所有真实手机、Safari 或微信内置浏览器均已验证。

使用 Chromium 移动端与触控模拟，中文界面、上海时区。基础尺寸为 320×568、375×667、390×844、430×932、768×1024、844×390；分别检查浅色、深色主题。另检查 760/1023/1024px 顶部布局断点。没有禁用用户缩放，也没有用隐藏滚动条掩盖超出屏幕的内容；长文章与设置页面允许正常纵向滚动。

最终回归：105 项通过、0 失败、0 跳过。正式账户隔离模拟 12 组通过。线上功能流程 14 组通过，144 组页面组合没有发现页面横向溢出或平板顶部文字换行。

回归过程中曾出现一次桌面插画间距的时序断言失败，单独重测通过；检查已改为等待实际不重叠条件并在同一帧测量，保留原判定标准，随后完整 105 项重跑通过。

## 已修复

| 问题 | 修复与复验 |
| --- | --- |
| 移动登录输入框为 15px，阅读偏小 | 手机登录、验证码输入统一至少 16px；注册原有 16px 保持不变，重查小屏布局和输入可达性 |
| 两个专题练习入口沿用三列，标题被挤成单字换行 | 小屏专题入口改为两列，下面三种练习模式维持原布局；320/375/390/430px 文字排版测试通过 |
| 环境声浮层在 320px 伸出左边，横屏底部控件超出屏幕 | 浮层定位到可视区域，限制高度并允许内部滚动；尺寸变化时重新定位；补充键盘焦点、Esc 返回、外部点击关闭与搜索快捷键收起，验证缺少 ResizeObserver 时可降级运行 |
| 768/844px 顶部搜索框挤压品牌和导航 | 760–1023px 使用紧凑搜索图标，品牌与导航保持一行；搜索的可访问名称和点击行为保留，≤759px 与 ≥1024px 原布局不变 |

修复未改变账户服务、数据库结构、游客到期策略、验证码规则或 SMTP 配置。

## 正式账户：隔离环境模拟

使用临时 SQLite、真实 HTTPS 应用处理器和内存邮件箱；不在生产账户库创建用户，不发送真实邮箱验证码。390px 触控环境完成以下 12 组检查，同时保留原有多尺寸资料面板检查：

1. 未登录时进入独立认证页，不出现认证弹窗。
2. 邮箱注册校验六位验证码，注册后邮箱标记已验证。
3. 登录后账户菜单、注册资料、个人中心可使用，资料面板没有内部横向溢出。
4. 正式账户快照同步、云端备份及权限隔离。
5. 用户名注册，不能读取另一个账户的备份。
6. 邮箱加密码登录并恢复原账户。
7. 邮箱验证码登录、用途绑定、五分钟有效、一次性使用及服务重开后验证。
8. 修改密码后撤销会话并返回登录页。
9. 未登录访问受保护路由回到认证页，并可进入游客模式。
10. 主要路由不恢复旧会员收费或 GitHub 展示。
11. 会话失效时回到登录入口，不删除原账户本机资料。
12. 管理员测试账户在手机屏幕查看管理页面，资料不超出页面宽度。
