## 安全复核与修正

- 独立代码复核发现邮件繁忙/发送失败响应可能区分邮箱是否存在，已改为统一接受响应及有界异步发送，并增加对应测试。
- “请求已接受”不等于邮件已投递；页面文案明确仅尝试发送。全局缺少邮件配置时统一提示不可用。
- 登录 POST 与初始化会话 GET 共享跨标签页 Web Lock，避免凭据更新竞态；回归测试已验证。
- 保留 HTTPS、CSRF、账户所有权校验、乐观并发控制及存储配额。生产依赖审计为零已知告警，但不代表不存在未知漏洞。
- 邮件授权码和验证码摘要密钥位于 root:root 0600 的 `/etc/word-atlas/mail.env`，未进入前端资源、代码报告或日志。前端 JS/CSS 已检查不含配置密钥。

## 运行边界
