# 词与远方管理后台

入口：`https://west.cloud-ip.cc/#/admin`。管理员从首页或任意学习路由登录后均自动进入独立后台，不展示普通学习界面、不加载词库或启动学习云同步。普通账号即使知道入口也不能读取运维接口，不能导入证书或被自动提权。

## 管理员首次设密

在主机 **root 交互终端**运行 `/usr/local/bin/words-admin-setup`，输入两次自行选择的密码；不会回显，也不接受命令行密码参数或管道输入。用户名固定为 `admin`，公开注册已保留该名称。没有默认密码，也没有将密码发送到聊天或邮件的流程。

密码规则：8–128 个字符，包含大写、小写、数字与符号。已有管理员忘记密码时，root 可运行 `/usr/local/bin/words-admin-setup reset`；只重置既有管理员，不会将同名普通账户提权，并撤销该管理员会话。

## 页面与状态含义

左侧菜单包括运行概览、在线用户、登录历史、账号管理、SSL 证书、安全与审计。系统服务状态目录暂时停用：不展示、不调用 systemctl 采集项目或系统 service/timer，旧目录接口对管理员返回 410 `services_disabled`，受限组件也拒绝 `services` 动作。运行时间、主机资源与内部组件配置检查保留。

后台使用紧凑视口布局；长列表分页，证书及安全表单分区展示，不通过隐藏溢出来裁切内容。退出入口留在后台导航，不跳转个人中心。登录历史支持 `limit=1..50`（默认 50）以适应不同屏幕高度。

项目运行时间是本次应用进程启动后的时长；主机运行时间是系统 uptime。邮件等内部组件的“就绪”表示配置/加载情况，不代表主动发送测试邮件成功。后台不主动发送验证码。

在线列表是有效登录会话的汇总，最近 5 分钟有可信操作的身份另标为活跃。轮询不算操作。游客展示生成的临时用户名，仅从游客库查询当前身份，不写永久登录历史。历史从此功能上线后记录正式账户注册登录、密码/邮箱验证码登录成功失败、退出和超时，不补造此前未记录的历史；最多保留 90 天、10,000 条。

正式账户与管理员仍使用 120 分钟闲置登录截止，游客为 240 分钟；数据保留规则不变。

## SSL 证书

上传完整 PEM/CRT 证书链（最多 96 KiB）与匹配的未加密 PEM 私钥（最多 16 KiB）。同时接受 RSA-2048 及以上、合适强度 EC 等受支持算法；不接受 PFX/JKS/加密私钥。证书须匹配 `west.cloud-ip.cc`、在有效期内且至少剩余 1 小时、具有完整可信链，私钥必须匹配。只支持域名 HTTPS，不要求新证书包含 IP SAN。

操作流程：上传并重新验证管理员密码 → 校验并暂存 → 查看有效期/颁发者/指纹 → 再次确认并应用。暂存 15 分钟过期且只能使用一次。私钥不回显、不下载、不写入浏览器持久存储、登录记录或审计。

受限组件创建版本化证书目录，以原子 `current` 链接切换证书和密钥；应用进程通过固定信号热加载，不因换证清除登录或重启。组件随后验证真实 HTTPS 端点指纹，失败恢复旧版本并再次验证；恢复无法完成时明确报告异常，不假报回滚成功。可回退到上一受管版本。

手动应用后进入手动模式，现有 ACME 任务仍可续期其自身证书，但部署钩子不会覆盖手动证书。切换自动模式会使用固定 ACME 证书路径，经过同样校验/应用/验证流程。手动证书不会自动续期，请留意到期提醒。

## 权限与审计

应用仍以 `word-atlas` 身份运行；受限组件使用 root，但只暴露权限受控的 Unix socket，无公网端口，无任意文件路径或 shell 命令参数。只允许证书读取元数据/暂存/应用/回退/自动模式与操作审计查询，不再允许系统服务查询。

证书操作有两层记录：账户数据库中的请求审计，以及独立组件 root-only 操作日志。即使浏览器超时或断开，组件仍记录最终结果。`requested/started` 只表示已提交；`success` 为组件完成；`uncertain` 需检查当前证书，不应盲目重试。组件崩溃时未完成的日志在重启后标为待确认。

关键位置：
- 应用会话/历史：`/var/lib/word-atlas/accounts.sqlite`，schema v4。
- 游客：`/var/lib/word-atlas/guests.sqlite`，仍按原期限清理。
- 当前证书：`/etc/word-atlas/tls/current/`；原始部署证书保留。
- 证书暂存、状态、独立审计：`/var/lib/word-atlas-admin/`，root-only。
- 固定组件：`/usr/local/lib/word-atlas-admin/`；服务 `word-atlas-admin.service`。

备份迁移/回滚时同时保护数据库、TLS 版本目录和组件状态。若回滚到旧程序，账户 schema v4 需要使用一致的迁移前备份配套恢复，不能直接将旧代码指向新 schema；恢复数据库前先停止应用并保留当前副本，避免丢失上线后的新学习记录。
