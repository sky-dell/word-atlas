# 账号、会员与数据生命周期检查

检查日期：2026-10-29。范围：免费注册、管理员授权会员、浏览器账号隔离、云同步、备份恢复及部署。以批准的账号会员设计为准，不包含支付、邮箱验证或短信找回。

## 结论

修正下述问题后，当前单机、小规模部署的数据边界与生命周期设计合理；功能和数据持久化测试通过。临时登录凭据与长期账号、会员授权、学习数据分开保存，会员到期不删除用户数据。并不承诺浏览器数据永不丢失、同机备份具备异地容灾能力，或已经完成大规模压测。

正式入口：`https://43.133.166.184/#/account`；管理员入口：`#/admin`。HTTP80 仅保留原学习和导出功能，不接受注册登录。HTTP 用户须先导出，再在 HTTPS 下导入，两个浏览器来源不会自动共享 IndexedDB。

## 生命周期与隔离

| 类别 | 设计与检查结果 |
| --- | --- |
| 账号与密码 | SQLite 持久保存；唯一用户名；密码加盐 scrypt，不保存明文；注册只能创建普通用户 |
| 登录与短期凭据 | Secure/HttpOnly/SameSite=Lax cookie；库中只存会话 token 哈希；登录最长7天，匿名CSRF1小时，重置凭据30分钟且一次使用，管理员二次验证5分钟 |
| 会员 | 限期授权与永久标志分别保存；实时检查到期、取消和禁用，不依赖前端状态；服务重启保留永久会员 |
| 本地持久数据 | 游客沿用原存储；每个账号独立命名空间；切换账号取消旧请求、限制旧异步回调，跨标签页重新验证身份；导入游客记录须明确选择 |
| 临时学习过程 | 未完成答题会话只用于本机接续，不混入云端学习快照；退出不清空该账号长期记录 |
| 云端快照 | 所有者取自服务端会话；每账号每词库单独保存；CAS版本冲突要求用户先备份再选版本，不静默覆盖 |
| 用户备份 | 每词库保留最近3份；会员到期后仍能下载本人已有备份；恢复前先下载当前本机副本 |
| 运维备份 | SQLite一致性备份，每晚执行、保留7份；备份目录0700、文件0600；恢复旧库后必须撤销旧会话和重置凭据 |

短期凭据到期立即不可使用，物理清理在后续 API 请求时执行。普通重启不清除有效登录；退出、改密、重置、禁用则撤销相应会话。

## 已修正并覆盖回归的问题

1. 本机存储提交失败时仍可能继续云同步：同步现等待本机持久化成功，失败不上传、不确认已同步。
2. 恢复备份可能遗留旧的附加记录：只替换当前账号数据，移除旧快照多余项；中途配额写入失败回滚附加记录，不推进主学习状态。
3. 前后端插画偏好数量边界不一致：统一结构与大小限制，覆盖超过200个单词偏好的正常场景。
4. 云存储只有单次请求限制：增加每账号40MiB、全站512MiB的快照与备份总量限制，按替换和淘汰后的实际增量检查，不在超额时删除原记录。
5. 请求体并发及认证请求占用过大：认证/管理请求16KiB、云请求10MiB、全局最多4个正在读取的请求体；未授权/未知接口先拒绝再读入。
6. 生产数据库缺失可能被当成新部署：改为显式本机初始化，生产启动要求已初始化的正常库，缺失或空库报错。
7. 会话达到上限时已有登录无法轮换：会话替换按净增量计算，在事务内完成。
8. 整库恢复可能重新激活旧凭据：提供本机 `invalidate-sessions` 命令，保留账号、授权、学习记录，清除所有会话及重置凭据。
9. 备份/撤销会话命令对已存在的零字节库可能自动初始化：新增真实CLI失败复现并修正为严格打开；只有显式初始化或本机创建管理员可以初始化库，普通运维操作拒绝空库且不写入结构。

测试等待机制也有修正：异步浏览器条件改为实际轮询服务端结果，避免等待提前结束造成持久化测试误判。

## 运维边界

- 没有默认管理员或默认密码。须在主机交互终端执行 `scripts/admin.mjs create-admin --username owner_admin`，由所有者输入密码；详细命令见 `ACCOUNTS-OPERATIONS.md`。
- 备份当前仍在同一主机，未配置异地备份；主机整体丢失仍存在风险。浏览器命名空间隔离不是本机磁盘加密。
- API禁止Service Worker缓存；普通用户不能管理会员；过期会员不能新增云写入；恢复、改密不会删除该用户已有学习记录。
- 每账号与全站限额保护当前单机资源，并非性能容量承诺；账号、审计记录的长期增长仍需监控磁盘。
- 更新程序不能覆盖 `/var/lib/word-atlas`。不要对正在服务的 `dist` 直接运行清空式构建；应在独立工作树构建后发布，并保留程序回退副本。
