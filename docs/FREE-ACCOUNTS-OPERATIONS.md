# 免费账户与邮箱验证码邮件运维

当前账户体系只有免费注册账号及本机创建的管理员角色。不存在收费、会员开通、期限或授权门槛。用户可选择用户名注册，或经邮箱六位验证码验证后注册；邮箱账户可用邮箱+密码或邮箱+验证码登录。旧用户名账户继续使用原密码，未验证绑定的邮箱不能用于登录。

## 入口和数据

登录、注册和凭据重置集中在独立品牌进入页。右上角仅在登录后提供账户下拉菜单：个人中心、真实账户注册信息、账号安全、同步/备份及退出；不使用居中Sheet或全屏蒙层。游客只显示返回入口控件，不展示认证下拉或游客徽标。进入页直接显示登录表单，邮箱服务可用时注册默认邮箱验证，保留用户名注册；游客选择仅在当前标签页临时保存，返回入口不会清空学习记录。所有启用账号均可同步和备份；资料仍按服务端会话所有者和词库隔离，CAS冲突需先备份再选择，不静默覆盖。注册用户登录后会自动恢复当前账户最新云端学习快照，不需要先手动创建备份；手动云端备份每词库保留最近3份，用于历史回滚。

服务源码 `/data/word-atlas`；进程 `word-atlas.service`；HTTP80继续游客学习/导出，账户仅HTTPS443。数据库 `/var/lib/word-atlas/accounts.sqlite`（0600），升级为v2时保留旧用户主键、密码哈希、学习记录、备份及会话，增加验证邮箱与临时码表，不重建原库。旧member API/响应字段仅作兼容，不再决定权限。管理员管理页只提供禁用/恢复、审计及受控重置，不提供会员操作或网页提权。

最新云端学习快照持续保存、无自动到期；云数据配额仍为每账号40MiB、全站512MiB，每词库最近3份用户手动云备份；一致性整库备份每晚保留7份，同机备份不等于异地容灾。

## 邮件配置

`#/admin` 的“邮件服务”支持任意 SMTP 服务商。配置字段为 SMTP 主机、端口、加密方式、登录账号、SMTP 授权码、发件地址和发件人名称。加密方式只支持隐式 TLS 与 STARTTLS；两者都强制校验证书并使用 TLS 1.2 以上。SMTP 主机必须解析到公网地址，不接受明文 SMTP、回环或私网地址，也不支持 Resend、SendGrid 等 HTTP API 邮件服务。

首次配置必须录入授权码。已有配置时授权码留空表示保留原值，更换服务商或凭据时才录入新值。授权码为只写字段，服务端不会通过状态接口、审计或日志返回或保存已保存授权码的明文副本。

“验证连接”和“保存配置”都会要求重新输入当前管理员密码，并经过现有 HTTPS、可信 Origin、CSRF、短时重新认证和独立限流。保存需要受限本地助手可用；助手以固定 `mail-save` 动作，在 root 目录内通过临时文件、fsync 和原子重命名更新 `/etc/word-atlas/mail.env`。文件必须为 root 所有、普通文件且权限 0600，更新时保留现有验证码 HMAC 密钥。管理页保存成功后会动态替换 SMTP 运行时，无需重启服务。

更换服务商时，在“邮件服务”填写完整的新主机、端口、安全模式、登录账号、发件地址和发件人名称；凭据未变化可留空。先验证连接，再保存。

管理页或助手不可用时，可从 root 交互终端执行回退命令；授权码只通过隐藏终端输入，不能放入参数、环境变量或管道：

```bash
/usr/local/bin/node /data/word-atlas/scripts/configure-mail.mjs
```

已有配置时，只有明确替换才添加 `--replace`；授权码留空会保留原值。不要复制该文件到项目、聊天或静态目录。CLI 只写文件，不会通知正在运行的 Web 进程，因此用 CLI 修改后需要重启服务才能加载；管理页保存不要求重启。

root 下可以向当前配置的发件地址发送一封接入测试邮件，不产生登录验证码：

```bash
/usr/local/bin/node /data/word-atlas/scripts/test-mail.mjs
```

SMTP接受不等于收件箱投递；本次用户已经确认收到接入测试邮件。验证码业务E2E使用独立临时HTTPS/SQLite和捕获发件器，不向生产创建测试账号、不发送测试验证码到外部用户。

## 验证码与故障

六位数字含前导0，五分钟有效（到达截止时间即失效），注册/登录用途分开，单次消费，60秒重发冷却，重发旧码失效，最多5次错误。邮箱/IP/全局发送限制持久化，发送并发和超时有界。数据库只保存HMAC，SMTP授权码不进库。改密、禁用、重置会撤销相关码。

邮件配置缺失时会话API的emailEnabled为false，邮箱方式显示不可用，用户名注册/密码登录继续工作。发码接口的正常响应代表接受请求并在符合条件时尝试发送，不能凭响应推断邮箱是否已注册或证明邮件实际送达；实际失败不能留下有效新码。请检查收件箱/垃圾邮件，必要时等待冷却后重试，不要绕过限流或使用固定码。

## 管理、备份及恢复

管理员仍须本机交互创建，无默认密码：

```bash
runuser -u word-atlas -- /usr/local/bin/node /data/word-atlas/scripts/admin.mjs create-admin --username owner_admin
runuser -u word-atlas -- /usr/local/bin/node /data/word-atlas/scripts/admin.mjs backup
```

恢复前停止服务并保全当前数据库/WAL/SHM，使用一致性备份，恢复文件owner为word-atlas、0600；重新启动前执行 `scripts/admin.mjs invalidate-sessions`，清除会话、重置凭据和邮箱码，防止旧备份复活临时凭据。旧SMTP配置与HMAC密钥独立保管，不从用户学习备份中恢复。
