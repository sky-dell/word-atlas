# 闲置登录超时

已确认：正式账户闲置 120 分钟、游客闲置 240 分钟后需要重新进入登录流程。后台轮询不算操作，学习记录保留。

采用服务器强制截止时间与浏览器操作心跳结合的方案。仅前端计时可绕过，按固定登录时长过期则会中断持续学习，因此不采用。点击、键盘输入、滚轮/触摸操作可触发限频心跳；会话查询与云同步不续期。所有续期必须通过现有同源、身份与 CSRF 检查，已过期会话不能被心跳复活。

正式账户保留原有 7 天绝对上限，新增 120 分钟滚动闲置截止。游客新增 240 分钟登录截止，与闲置 24 小时/最长 7 天的数据清理截止分开。游客超时保留 Cookie 和暂存资料，明确点击游客入口后可继续原身份；刷新不得绕过超时。

前端在截止、页面恢复、跨标签页操作时向服务器核验；失败时不继续显示私有账户页面。超时不删除账户、备份或游客记录。使用可推进的测试时钟验证边界，不修改生产时间。

游客自动恢复仅查询状态，不调用续期入口。超时前未同步的本页资料以临时内存快照保留，重新进入同一身份时恢复；若服务器版本已变化则显示冲突并禁止自动覆盖，可先导出。入口提供未暂存资料导出，刷新前保留浏览器离开警告；不将这些临时资料写入永久浏览器存储。

上线时会话存储进行向后兼容的增列迁移。既有正式会话按创建时间、既有游客按最近数据活动时间计算初始截止，不统一延长旧登录；已有学习记录不变。
