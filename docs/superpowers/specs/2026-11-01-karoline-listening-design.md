# 卡罗琳听力训练设计

日期：2026-11-01。状态：待用户批准；未实施、未部署。

## 意图与已确认选择

为「词与远方 · Words & Beyond」增加真实新闻发布会视频听力练习。用户确认素材人物为 Karoline Leavitt（卡罗琳·莱维特），选择方案三：完整视频与问答片段精听结合。在书房现有「原版书」「词与远方短文」旁增加「卡罗琳」入口，不新增顶级导航。

## 方案比较

1. 完整发布会播放：保留语境，开发简单，但找练习片段困难。
2. 仅问答片段：训练集中，但缺少完整上下文。
3. 完整视频 + 问答精听：同一视频在完整观看与片段练习间切换，保留语境且适合反复练习。用户已选；内容核验与播放器联动成本更高。

## 目标、非目标与失败条件

- 目标：进入书房找到素材、播放真实视频、按问题定位、重复收听、查看经校对的英文与中文释义、完成短听写、恢复个人进度。
- 首版由工程师建议限定为一场真实发布会、至少三段完整问答，每段约 30–180 秒（可因句子完整适当调整），含可练习句及重点词。后续以静态内容包扩充，无须开发后台。
- 非目标：自动抓取新闻、批量 AI 转录服务、实时直播、录音上传、口语评分、独立收费会员、新数据库或运营后台。
- 失败条件：只有链接而无可用精听、伪造字幕或时间轴、把模拟播放器测试当作真实播放验证、自动播放、破坏既有阅读/账户/游客隔离。

## 信息与视觉设计（工程师建议）

- 保留全站现有奶油色背景、藏蓝文字、陶土红点缀、圆角与深色主题，不另建 Premium Dark 页面。
- 书房顶部三个同级胶囊按钮：「原版书」「词与远方短文」「卡罗琳」。第三项仅在听力页激活。
- 列表页：标题「卡罗琳 · 新闻发布会听力」，简短说明、日期与主题卡片，明确展示时任白宫新闻秘书身份、素材来源、难度为编辑估计而非标准认证、可练习片段数、继续学习入口。
- 桌面详情：左侧主视频（16:9），下方完整观看/片段精听切换、播放速度与当前片段循环；右侧问答列表。下方英文逐句稿、按需显示中文释义、重点词与听写。
- 手机：播放器、片段选择、文本与练习纵向排列；无水平滚动或嵌套长滚动区。长学习内容允许正常页面纵向滚动，不套用注册页无滚动的特殊要求。
- 点击片段定位开始，播放到片段尾停止；启用循环后回到开始。完整模式不受片段尾限制。拖动到片段外时退出当前循环并清晰提示，避免强行拉回。
- 英文支持隐藏/显示，中文默认隐藏；逐句点击定位，播放高亮当前句。无逐字时码则不承诺逐字高亮。
- 重点词可打开既有词卡；词库无收录时展示本内容包的解释，不伪造词库条目、不自动更改 FSRS 进度。
- 短听写以句为单位，默认遮住答案，提交后显示标点/大小写归一后的差异及原文；仅标识本句完成，不声称雅思评分。
- 键盘可操作、焦点可见、状态通过 aria-live 通知；降低动态偏好时禁用非必要动画。

## 素材、播放器与上线门槛

- 已发现白宫官方页面（2025-01-28），其原视频嵌入地址指向 YouTube ID `xJOgsQQYDY4`。官方页面存在不等于播放器在用户网络可用；当前尚未验证嵌入成功、字幕获取和具体问答时间点。
- 首选使用官方视频的 YouTube IFrame API 嵌入，不下载、代理、重新托管或绕过平台限制。平台 API 支持播放、定位、状态事件及速度查询；只展示实际支持的速度。脚本懒加载，用户点击后才初始化播放器，不自动播放。
- 以播放器适配器隔离 UI 与平台调用，未来可接入有授权的 HTML5 视频；首版不搭建视频存储/CDN。
- 显示官方原文链接及原视频链接。超时、区域/平台封锁、禁止嵌入、视频删除、无网络等显示明确错误与重试/打开原视频，不显示假的播放成功；未 ready 时禁用定位和循环。
- 原视频链接只是降级，不替代核心训练验收。如果官方源在目标使用网络不可播放，停止宣称功能已交付，向用户报告，并由用户选择可访问且获授权的视频来源；不擅自搭建代理或付费服务。
- 实施时先核验真实视频可播放和时间线，再整理至少三段问答、逐句时码、英文校对及中文释义。仅使用来源与使用权限可核实的内容；不把第三方整篇转录直接复制入库，不默认政府页面上的所有第三方素材均可再分发。
- 内容注明原始来源、发布日期、转录方式、校对状态与核验日期；翻译为学习辅助，不作为官方译文。媒体内容仅供语言练习，不作为项目背书。
- 若无法合规获得/整理准确字幕或核验时间点，不用占位文字假装内容齐备；报告该发布门槛，保持线上原功能不变。

## 结构、路由与内容契约

- 沿用 React + TypeScript + Vite 和现有 CSS/图标，不新增大型 UI/后端依赖。
- 扩展 read 路由的 tab 为 `karoline`，详情用 `id`、片段用新增 `segment`：`#/read?tab=karoline&id=<id>&segment=<id>`。读写路由一起更新；非法视频或片段显示可返回列表的状态，不误落入原版书/短文详情。
- Reading 只负责入口及分发，新听力组件/播放器/数据层独立，避免把训练状态塞入既有段落朗读。
- 静态内容包包含 version、稳定 video/segment/sentence ID、标题、日期、来源 URL、provider/videoId、核验状态、片段起止、speaker、英文句子及起止时码、中文释义、词汇和听写句 ID。列表索引单独加载，详情按需读取。
- 内容校验：所有时间为有限非负数，start < end，句子处于片段内，片段在已核验视频时长内，引用 ID 存在、无重复。仅 published 且 verified 的条目对外展示。纯文本渲染，URL 协议及媒体域名白名单，不接收用户注入的 iframe 或 HTML。
- 离开页面、切换账号/游客身份或播放其他应用音频时暂停并释放播放器/监听器/计时器，保证不会后台继续播放或串写身份。

## 数据与生命周期

- 视频/转录是公共静态内容，不写入用户数据库。用户记录只含内容版本、当前视频/片段、有限播放位置、已完成句/片段、最近学习时间和显示偏好；不保存影音文件或大段文本。
- 复用当前 dataset 的 `word-atlas:extras:v1:<datasetId>` 记录内新增有版本的 listening 字段，先检查现有 extras 合并方式，确保不覆盖其他功能。通过既有 profileStorage/快照接口保存，禁止旁路使用未隔离的 localStorage。
- 正式账户沿用本机账户隔离与现有账户快照同步/备份，永久数据库仍为 `/var/lib/word-atlas/accounts.sqlite`。游客仍在 `/var/lib/word-atlas/guests.sqlite` 中临时保存，沿用空闲 24 小时、绝对 7 天及清理逻辑，不创建永久账户。
- 游客转账户不自动搬运，继续仅在明确导入时复制。账户 A/B/游客互不读取进度；身份切换后取消上一身份尚未完成的保存任务。
- 播放中最多每 30 秒标记一次位置变化，暂停、切片段、完成练习、页面隐藏/离开时走现有合并/去抖保存。记录未变化不重复保存、不为后台播放器心跳延长游客 TTL；失败显示未保存且允许重试。
- 限定最多保留最近 100 个视频的学习记录；不持久化未提交听写文本，防止进度无限增长。内容版本变化时，仅恢复仍存在且合法的 ID 和位置，其余重置并提示。
- 自动完成片段需实际播放覆盖达到 80% 且到达末尾，纯拖动不计；提供显式「标记完成/取消」操作，不将完成状态视为考试成绩。

## 验收与回归

1. 路由、静态包合法性、进度合并/隔离/版本迁移、听写判定、循环边界及清理逻辑单元测试。
2. 可控假播放器 E2E 验证完整/片段切换、定位/循环、字幕/释义、听写、错误重试；报告明确其不证明真实媒体可达。
3. 真实官方视频手动或浏览器联调：播放、暂停、至少三段定位、倍速及循环，记录来源、日期与结果；目标用户网络需验证，服务器能访问不等于用户端能播放。
4. 正式账户刷新/重登恢复、账户隔离、游客短时刷新恢复、到期清理、明确导入、退出身份无串写，复用现有隔离测试服务，不能清理真实生产用户数据。
5. 桌面与手机、明暗主题、键盘操作，无横向滚动；原版书/短文、注册/密码和验证码登录、账户菜单回归。
6. 测试通过后才按既有备份与发布方式部署；不自动提交/推送全部已有脏改动，不修改 SMTP 设置，不发送真实验证码邮件。实测不足须在交付说明列出，不以 mock 测试掩盖。
