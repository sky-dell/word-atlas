# Word Atlas Online Parity Implementation Plan

**Goal:** 在 /data/word-atlas 开发、部署并验证与线上可观察功能对应的独立应用。

**Architecture:** 延续 MIT 开源 React/TypeScript 应用，保留 CC BY 署名。使用本地词库与媒体、FSRS、本地持久化。新增书房、同义替换、易混词与外观配置；独立静态 HTTP 服务监听 5188，不影响 80 端口已有项目。

**Reference:** https://0xlei.tech/words/#/atlas；线上独立迭代，新增功能采用可维护源码实现，不把压缩产物当作源码。

## Tasks

- [x] 持久化：IndexedDB、旧数据迁移、写入失败重试、标签页并发与异常路由回归测试。
- [x] 外观：星光/极光、字体、图鉴文案、词卡与设置。
- [x] 书房：短文目录、阅读、翻译、词卡、理解题、阅读状态；原版书目录与章节。
- [x] 专项：同义替换关卡、易混词组与答题反馈，统计独立于 FSRS。
- [x] 同步线上公开词条索引/分块，校验资源覆盖；保留内容来源说明。
- [x] 接入路由、导航与练习入口，错误状态、动态导入。
- [x] 构建、单元测试、词库校验、桌面/手机浏览器功能测试。
- [x] 部署 systemd 服务，HTTP、音频 Range、重启持久性验证。

## Acceptance

以功能清单逐项记录通过、差异和未覆盖项；不以“能构建”代替功能测试。不修改原有服务，不推送远程仓库。测试使用独立浏览器 profile，不污染用户学习进度。
