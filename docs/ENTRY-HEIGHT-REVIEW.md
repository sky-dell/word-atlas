# 登录页视口高度优化 · 2026-10-30

## 范围与设计

保留现有纸色/深色主题、品牌、双栏和插画设计，只优化入口页高度。桌面按窗口高度收紧留白与装饰卡片；手机端保留品牌标识，省去重复宣传区，优先展示完整登录与游客入口。低高度窗口减少辅助文案，不缩小输入框或主要操作。

不通过 `overflow:hidden`、固定高度裁切、全页缩放或隐藏滚动条实现。登录在常用尺寸无滚动；注册、错误反馈、极矮窗口及软键盘场景可按内容自然滚动。账户业务、学习页面、数据库和邮件配置不变。
